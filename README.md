# 차지호 국회의원 명함 QR 링크 페이지

명함에 인쇄된 QR을 찍으면 열리는 링크 모음 페이지입니다.
**QR은 주소만 담고 있으므로, 이 저장소의 내용을 바꾸면 이미 배포된 명함에도 즉시 반영됩니다.**
(= 내용이 바뀌어도 명함을 다시 찍을 필요가 없습니다)

**이 두 주소는 절대 바꾸면 안 됩니다.** 바꾸면 배포된 명함의 QR이 전부 죽습니다.

## 주의사항 (수정 시 반드시 지킬 것)

### 1. 계좌번호와 전화번호는 하이픈을 쪼개놓았음
```html
농협 301<i>-</i>0346<i>-</i>4145<i>-</i>51
```
iOS 사파리가 숫자+하이픈을 **전화번호로 자동 인식해 파란 링크로 바꿔버리는 문제**가 있어서,
하이픈을 별도 요소로 분리해 인식을 차단한 것입니다.
**이 `<i>` 태그를 지우면 글자가 다시 파랗게 변합니다.**

`<head>` 의 `format-detection` 메타 태그도 같은 목적이므로 삭제 금지.

### 2. 다크모드 강제 변환 차단
`<meta name="color-scheme" content="light only">`
일부 안드로이드 브라우저가 색을 반전시키는 것을 막습니다.

### 3. 파일 업로드 시 이름 확인
브라우저가 다운로드할 때 `index_2.html` 처럼 이름을 바꾸는 경우가 있습니다.
올리기 전에 **반드시 파일명이 `index.html` 인지 확인**하세요.

## 수정하는 방법

### 간단한 글자 수정 (링크 주소, 전화번호 등)
1. GitHub에서 해당 파일 클릭
2. 오른쪽 위 **연필 아이콘**
3. 고친 뒤 **Commit changes**
4. 1~3분 뒤 반영 (Actions 탭에서 초록 체크 확인)

### 파일 통째로 교체
1. **Add file** → **Upload files**
2. 같은 이름으로 올리면 자동 덮어쓰기
3. **Commit changes**

### 반영이 안 될 때
브라우저 캐시입니다. 주소 뒤에 `?2`, `?3` 처럼 숫자를 붙여서 열어보세요.

| 차지호QR_영문_명함인쇄용_벡터.svg | 영문 / 인쇄소 전달용 |
| 차지호QR_영문_화면SNS문서용.png | 영문 / 화면·문서용 |

### 인쇄 시 주의
- **최소 15mm 이상** (명함은 18~20mm 권장)
- **QR 바깥 흰 여백을 자르지 말 것** — 인식률이 크게 떨어집니다
- 배경은 흰색 또는 아주 밝은 색
- **인쇄 전 실물 크기로 뽑아 아이폰·안드로이드로 각각 테스트할 것**
